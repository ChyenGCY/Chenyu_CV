education, research and work experience, publications, patents, projects, awards, and skills.

Modified from arasgungore's cv.

| File | Length | Purpose |
| --- | --- | --- |
| `CV.tex` | multi-page | Full academic CV |
| `CV-short.tex` | multi-page | Condensed academic CV |
| `resume-general.tex` | multi-page | General-purpose resume (all experience, publications, patents, projects, awards) |
